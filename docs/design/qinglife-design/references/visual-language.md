# 视觉语言

本文件是词汇表，不是模板。叙事页从中选 1–2 个签名作锚点，也可以发明新的；任务页只需要字体、色彩与动作的一致性。

## 1. 字体角色与字阶（375px 参考）

| 角色 | 用途 | 参考尺寸 / 行高 | 字体与字重 |
| --- | --- | --- | --- |
| 题字 | 首屏或段落的一句「声音」 | 28–36px / 1.3–1.4 | 衬线 400–500；每屏最多一处 |
| 段题 | 分段标题、文章标题 | 20–24px / 1.4–1.5 | 衬线 400 或黑体 500 |
| 数字 | 日期、期数、统计成为视觉元素时 | 28–48px | 黑体或衬线数字 500–600，等宽数字 |
| 正文 | 叙事 16–17px；功能 15–16px | 1.75–1.9 | 黑体 400；长引语可用衬线 ≥18px |
| 辅助 | 事实标签、元信息、次级操作 | 14px / 1.6 | 黑体 400–500 |
| 注记 | 可有可无的补充 | 12–13px | 黑体 400；一屏一处以内 |

- 层级主要靠字号与颜色，字重只作辅助。中文只用 400 / 500 / 600。
- 衬线是「说话的声音」，不是装饰：用在需要语气的一句话上，而不是所有标题。
- 小程序当前仅首页固定短语用子集字体（Qinglife Opening，Noto Serif SC OFL）；其余衬线回退系统宋体，部分 Android 机型可能回退为黑体。设计在回退后仍须成立；新增衬线短语需评估子集与包体。
- 真实标题自然换行，不写死样稿断行。
- 不靠缩小字号解决溢出，也不靠全页小字制造精致。

## 2. 色彩角色

| 角色 | 用途 | 现行参考值（已验收首页） |
| --- | --- | --- |
| 纸 | 页面底色 | `#f7f6ef` |
| 墨 | 正文与标题 | `#252b21`（对纸 13.4:1） |
| 次墨 | 辅助文字 | `#666e5e`（4.9:1，只用于辅助，不用于正文） |
| 深绿 | 主动作、选中态、链接；唯一的「墨外」强调色 | `#435e3c`（6.7:1）；按钮底 `#344b30` |
| 浅绿 / 深纸 | 区域色场，一页一两处 | 例如 `#e8ecdf` |
| 线 | 结构分隔 | `#c2c8b9`（1.6:1，只作线，不作文字） |
| 陶土 | 少量温度点缀，不作动作色 | 全局 `--ql-clay` |

- 全局 `app.wxss`（「呼吸的纸面 V1.1」：`#F6F1E8`、陶土、鼠尾草、雾蓝、薰衣草）与首页页内变量是两套值，统一属于独立技术任务。新的品牌页以已验收首页的值为参照，组件沿用全局变量，不自造第三套。
- 全局 `--ql-ink-ghost #9A938A` 对纸色仅 2.7:1，不用于任何需要阅读的文字。
- 颜色表达语义：活动阶段、报名状态与费用状态分别表达，不一律用绿色。
- 避免科技渐变、蓝紫光晕、廉价促销红、霓虹色和大面积高饱和色块。

## 3. 签名构图（来自已验收首页，可沿用、变奏或替换）

- **错位题字**：两行开场，第二行内缩并换成衬线（「有空，／　来坐坐。」）。字本身就是画面。
- **单边出血**：照片贴住一侧屏幕边缘，另一侧留白；跨段落可左右交替。
- **内收正文栏**：段题靠左，正文和事实向内缩进一级，形成悬挂的阅读节奏。
- **细线起段**：组的开头一条细线；粗墨线只给唯一主推项。
- **图外文字**：文字不压在照片上，图注短而准确。

还可以使用的手段：一句话独占一屏的停顿、满幅照片后的纯文字段、大号数字与短标签的事实组、一次色场转场、引语放大成为画面主体。

**模板腔信号**（出现即复查是否真有必要）：每段都有眉题；所有模块同一种白卡圆角阴影；内容不是序列却用 01/02/03；「A · B · C」式元信息串；居中大标题＋三等分卡片；装饰性绿叶/水滴图标；渐变光晕；每个链接后的 ↗。

## 4. 摄影

**先定职责，再选照片。**

| 职责 | 回答 | 适合的画面 |
| --- | --- | --- |
| 氛围 | 这是怎样的地方和人 | 人与人正在交谈、走路、笑；环境可读 |
| 关系 | 有人带领、有同伴 | 导游与轻友、轻友之间的互动 |
| 动作 | 实际会做什么 | 拍打、伸展、冥想、讲解现场 |
| 细节 | 具体的质感 | 榨汁瓶、垫子、光线、手上的动作 |
| 肖像 | 这个人是谁、他说了什么 | 与故事人物身份一致的单人照 |
| 史料 | 时间与来历 | 经核实的创办人、早期资料照 |

- 选正在发生的瞬间、自然光、可读的人物关系；按主体与视线裁切；同一页里让尺度有大小之分。
- 不是每段都需要图。纯文字段往往让下一张图更有力量。
- 图片与文字讲同一件事：讲「回到日常」的段落，不配营内课程照；讲创办人的段落，只用创办人或史料。
- 带字海报完整可读；正文图片保持比例与原顺序；缺图或加载失败时退化为文字与原入口。
- 不用图库、AI 生成人物、带他人水印的公众号截图作主视觉，不从拼图中裁出单人冒充原图。

## 5. 容器、分隔与色场

- 先用对齐、邻近、留白和细线；独立容器只给确有边界的对象（一张期次卡、一组待核对字段）。
- 线分隔不同对象，不与 Tab 或固定栏边界重复；按筛选后的实际结果判断最后一项。
- 色场是节奏工具：一页最多一两处，用来标出「这里不同」，而不是给每段换底色。
- 不在页面上套 Card，也不给每个字段套 Card；按语义判断，不按类名判断。

## 6. 动效

- 默认静态阅读，不自动滚动真实文字，不加循环呼吸或漂浮动效。全局 `.page::before` 的 `ql-air-breathe` 无限动画与此冲突，首页已关闭；新页面不应启用。
- 欢迎的动效：回应操作并说明变化，例如切换期次时信息原位更新、换一组心声、展开全文。
- 自动轮换：节奏缓慢，可手动切换，触摸、阅读或展开时暂停，尊重系统减少动态效果设置。
- 保留按压、加载与进度反馈；不可操作的状态不伪装成按钮。

## 7. 品牌词汇

来自业务方《轻生活调性文字》，可作为语气来源：慢下来、静下来、放下来；身要动，心要静；手到哪里，心到哪里；走出头脑，走进身体；细嚼慢咽；七分饱；简单生活；安心带来安睡；爱自己。

同一份材料里含健康主张（如「你不是病了，而是堵了」「水是最好的药」「症状代表神医在工作」「自然而愈」「餐叉胜于手术刀」），不用于界面或营销文案。

产品界面统一写「清体营」；历史文章原题中的「轻体营」引用时保留原文。
