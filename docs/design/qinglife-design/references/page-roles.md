## 新页面与模块重心（来自 2026-10-13 交接；数值未定，只给重心）

**首页 V2**（模块顺序已确认：品牌首屏 → 条件待办 → 近期清体营 → 亲友心声 → 了解轻生活）

| 模块 | 重心 | 设计要点 |
| --- | --- | --- |
| 品牌首屏 | 叙事 | 真实人物氛围；首页唯一的情绪高点 |
| 条件待办 | 任务 | 一条快捷信息；无待办完全隐藏 |
| 近期清体营 | 决策 / 任务 | 首页信息效率最高处；选中期次与原位切换清楚可读 |
| 亲友心声 | 叙事（轻） | 真实生活感、低占高；不与首屏争高点 |
| 了解轻生活 | 引导 | 引起深入阅读的入口，不讲完创办故事，不放信任数字 |

**认知转化页**（五段叙事已确认：短共鸣 → 创办故事 → 把轻生活，带回每一天 → 为什么有人愿意一次次回来？ → 透明说明与行动）

| 段落 | 重心 | 设计要点 |
| --- | --- | --- |
| ① 短共鸣 | 叙事（极轻） | 一句话的引子，不占满首屏，与②视觉连续 |
| ② 创办故事 | 叙事 · 证据 | 具体人物、年份与转折；只配史料或不配图 |
| ③ 带回每一天 | 叙事 · 方法 | 可理解的日常实践；图文同指「日常」 |
| ④ 一次次回来 | 叙事高点 · 证据 | 全页唯一情绪顶点（真实人物与原话）；数据作为另一种语法的证据 |
| ⑤ 透明说明与行动 | 决策 | 可扫读的实际安排与边界，与主动作同等可见 |

## 尚未单列目标的分支

- `friends` 为历史归档跳转，不新建社交 Feed，不另给比例。
- `personal/experience` 为单期经历与私人记录组合：分别参考参与经历 20/80、私人记录 35/65。
- `friend-flow/records` 为日常记录列表，区别于 `personal/records`；先核入口与数据，不合并两类记录。
- `mine-flow/experiences`、`mine-flow/experience` 有兼容 Demo 模板；先核当前入口，不作为正式能力美化。
- 工作人员其余视图：未单列目标，先核角色、入口与敏感权限，不纳入用户端设计批次。
- 统一清体营详情页如与 `camp-flow/detail` 合并或新建，需在 Brief 中重新确认角色。

## 已确认样板学什么

样板状态与待办以当前仓库 `docs/design/ui-boundary-samples-acceptance-20261010.md` 为准。样板用于学习判断，不是可复制的模板。

- 首页：有/无待办的焦点切换、真实摄影与错位题字的关系；不把品牌开篇复制到服务页。
- 活动详情：决策顺序、真实日程与规则；不固定课程天数或样稿段落。
- 公开活动列表：期数模板、快速比较、手动心声；不是其他列表必须用封面的依据。
- 我的安排：无封面任务目录、状态分离；不擅改其他页排序与落点。
- 报名：步骤、就近错误、真实提交核对；不把两步硬套到四步登记。
- 故事文章：标题、封面与富文本的自然适配；不把故事构图套到方法文章。
- 体验回顾：内容先读、私密边界、真实草稿与保存反馈；不扩大恢复范围。
