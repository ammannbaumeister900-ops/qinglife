# 「林下午后」视觉规范 · 轻生活小程序 2026Q4

> 配合 `PLAN.md` 使用。375px 为参考宽度，单位 px（与现有首页、认知页一致）。
> 可读性底线与事实边界以 `qinglife-design` Skill 为准；本文件只规定视觉方向。

---

## 1. 方向

**一句话**：午后林荫下，穿白色亚麻的人手里拿着一瓶绿汁，慢慢走着、说着话。

方向直接来自已授权的首页导游合影（`assets/brand/home-guides.jpg`）。树荫的深绿、白色亚麻、瓶中的绿汁、偏暖的午后光，都是只有轻生活才有的画面。用它们替换现在的"米纸 + 墨绿 + 衬线"，后者是生成式设计最常见的默认组合。

**要学的品质（只学品质，不抄页面）**
- 安缦 / 松赞：深色暗部、满幅环境照、极少的字、大量留白
- Kinfolk / Cereal：编辑式字阶、大数字、不对称版心
- 观夏：东方克制、单字或短句作画面

**不要**：米黄纸纹、毛笔字、禅石绿叶图标、渐变光晕、白卡圆角阴影、每段都有眉题、01/02/03 伪序号、每个链接都挂箭头。

## 3. 三个签名

### 签名一 · 一次深色
每页只用一次满宽深林色场（`--q-forest`）。
- 首页：品牌首屏（导航 + 题字 + 满幅照片 + 图注）
- 认知页：「为什么有人愿意一次次回来？」整段
- 清体营二级页、详情页：不用深色场，只用深林色做主按钮

### 签名二 · 数字即画面
已核实的数字放大后作为视觉主体，用 `--q-num`，等宽数字，字重 600。
- 首页日期：`10.01 — 10.03`，66px，墨色；下方一行 14px 写年份和天数
- 认知页 59.9%：112px，汁绿；`%` 48px
- 2007 / 500：48px，亚麻白；"多期"用衬线 20px
- 清体营列表期号：48px，墨色，替换现在的渐变海报

### 签名三 · 满幅真实，缺图用单字
- 有授权的照片一律满宽出血（左右不留缝），按原比例展示，不裁人；图注写在图外，14px
- 没有授权素材的段落不用图库，改用单字题眼：衬线 58px 苔绿单字（食 / 动 / 歇），三列，下方 14px 说明
- 照片和叙述必须指向同一个人或同一件事（邻接即指认）

## 4. 字体管线（`tools/fonts/subset.py`）

| 子集 | 源字体（OFL） | 字符来源 | 预算 |
|---|---|---|---|
| `Qing Serif` | Noto Serif SC SemiBold | `config/home-brand.js`、`config/brand-content.js`、`config/about-content.js` 中的固定标题 + WXML 中写死的标题 + 常用标点 `，。？、：；“”（）·—` | ≤ 45KB |
| `Qing Num` | Cormorant Garamond SemiBold | `0123456789.%+–—s` 和空格 | ≤ 12KB |

**规格**
- 依赖：`pip install fonttools brotli`
- 命令内核：`pyftsubset src.otf --text-file=chars.txt --flavor=woff --layout-features='*' --no-hinting --desubroutinize --output-file=out.woff`
- 输出 base64 后写入 `styles/qing-fonts.wxss`，格式参照 `pages/home/index.wxss` 第 1 行现有的 `@font-face` 写法。生成完成后，旧的 `Qinglife Opening` 可以删除，统一由 `Qing Serif` 替代。
- 脚本要打印每个子集的字符数和字节数；超出预算时报错退出。
- 只有固定文案用子集。接口返回的动态文本（营期名、文章标题）使用系统字体，版面必须在系统字体下也成立。
- Android 先测 woff；如不显示，改输出 ttf。

### 7.2 导出脚本 `tools/images/export.py`

- 依赖：Pillow。设置 `Image.MAX_IMAGE_PIXELS = None`（原图 6000 万像素）；先 `ImageOps.exif_transpose`。
- 按 7.1 表格裁切并缩放（LANCZOS），输出 JPEG：quality 78、progressive、去掉 EXIF（去掉 GPS 等元数据）。
- 体积上限：3:2 和 4:5 大图 ≤220KB，页头 ≤180KB，#67 ≤120KB，本地兜底 ≤120KB，分享 ≤128KB。超出时逐步把 quality 降到 70，仍超出则报错。
- 输出到 `F:/轻生活项目/轻生活/outputs/qing-images/`，文件名 `qing-<用途>-<编号>.jpg`，并写 `manifest.json`（编号、源文件、裁切框、尺寸、字节、用途、releaseReady）。
- 首页本地兜底覆盖 `apps/miniapp/assets/brand/home-guides.jpg`（文件名不变）；分享卡片（认知页 + 三张邀请卡）由 `tools/images/share-cards.py` 写入小程序包。其他图片不进包。
