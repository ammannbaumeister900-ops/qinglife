# S1 轻友心声结构收敛（2026-10-19 用户确认）

## 决定

- 写作内容统一叫「轻友心声」，写作入口统一为「写轻友心声」。首页「亲友心声」、清体营列表「轻友心声」展示区标题不变。
- 在这里写的内容默认就是要公开的：编辑器只有「公开发表」一个动作，提交后经运营内容审核与发布核对才展示，本人可收回。前端不再提供「仅自己保存」。
- 可写时间维持现有服务端窗口（方案 A）：活动前为开营当天至结营前，活动后为结营后；需本人报名已确认。没有扩展后端。
- 体验回顾只负责阅读与回望：本期私人体验记录（历史，只读）+ 本期轻友心声原文与审核/公开状态；唯一写入口跳转编辑器。

## 核验依据

- D4（2026-10-10）已实施且只覆盖活动后：私人原稿存 `ql_experience_record`，公开快照、审核、撤回存 `ql_camp_reflection`，同一事务；`uat/20261017-unified`、`uat/20261018-visual-integrated` 与当前 HEAD 均包含。验收记录现存于 `历史归档/2026-10-17-UAT版本收敛/protected-backup/files/docs/design/`。
- 收敛前：`camp-flow?view=feeling` 已无界面入口（孤儿页）；体验回顾页内编辑器只在演示环境出现；活动前「仅自己保存」的心声存在 `reflection.draft_note`，回望页看不到。

## 改动

| 位置 | 改动 |
| --- | --- |
| `pages/camp-reflection` | 去掉「仅自己保存」与 `savePrivate`；标题「轻友心声 · 活动前/活动后」；公开说明在按钮上方；状态文案取自 `utils/reflection.js` |

| `pages/camp` | 入口文案「写轻友心声」 |

不变：后端、接口、表结构、审核/发布核对/撤回、来源选择、历史长文/评分/匿名快照、150 字限制、身份作用域。服务端私人保存接口保留给旧客户端。日常记录不在范围内。
