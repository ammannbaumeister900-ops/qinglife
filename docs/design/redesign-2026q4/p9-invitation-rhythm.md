# P9 邀请轻友节奏谱（2026-10-19 用户确认）

## 统一原则：两处分享，一种体验

- **统一**：分享卡片模板、最后的分享按钮说法（「分享给朋友」）、先预览再分享。
- **不统一**：归属逻辑。认知页分享不记归属；邀请轻友按期次新建专属邀请码并记推荐归属，保留「生成」这一步（失败在分享前可见，不会把不带归属的链接当专属邀请发出）。认知页不加专属邀请入口。

## 邀请轻友页（`pages/referrals`）

| 区块 | 构图 | 强度 |
| --- | --- | --- |
| 导航 | `ql-nav-space`，亚麻底、返回键；去掉页面内重复标题 | |
| 回查入口 | 有推荐记录时一行「已有 N 条推荐报名记录，查看 ↓」，滚动到推荐记录（按记录条数陈述，不推断人数） | ● |

| 推荐记录 | 22 宋体区头 + 1px 墨线；小名、描边状态标签（文字）、期次、日期；发丝线分隔 | ● |

逻辑不变：身份监听、资格复核、`createInvitation`、分享路径与标题；切换期次清空已准备邀请，换卡片只换分享图（与原行为一致）。JS 只新增生成按钮的期号展示字段与滚动到推荐记录。
