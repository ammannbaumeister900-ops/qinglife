# 轻友心声署名规则

新投稿默认以轻友档案中的小名提交公开分享，可点击“匿名发布”。页面明确预览署名，并提示点击提交即同意经审核后在本期展示完整分享。仍保留“仅自己保存”。没有自动提交，也不会将历史私人草稿改为公开。

服务端从本人轻友档案取小名，客户端不能指定署名。提交时保存文字、小名/匿名方式和授权时间/版本；后台审核、选句、发布的流程不变。非匿名显示提交时的小名，匿名显示“本期轻友”；弹幕和点开的全文使用同一署名。后台可以查看该份投稿的公开署名与方式。

小名字段来源是 ql_customer.nickname。既有登记逻辑在未填写小名时可能将姓名填入该字段，因此页面显示实际将使用的署名，让轻友可选择匿名。字段为空时不能以小名投稿，可选择匿名；不额外使用 real_name 或微信昵称替代。

修改私人草稿或匿名选项只影响草稿。重新提交分享会立即停止原分享，等待重新审核，运营不能替本人修改署名方式。撤回仍停止后台和前台可见，草稿保留。

新增增量迁移 V1_4_9__camp_reflection_attribution.sql，旧记录默认匿名；旧版客户端未传匿名选项时也继续匿名，防止旧授权意外公开小名。既有1.4.8迁移文件不改写。管理员/运营权限不变，财务/领队权限不扩大。ASR继续关闭。

验证与发布记录保存在 .tools/acceptance-20261003-reflections-r6。未自动提交、推送或合并；生产不在本轮范围内。
