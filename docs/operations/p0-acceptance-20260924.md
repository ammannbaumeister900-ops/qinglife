## 建议验收用例

1. **后台登录与菜单**：四个账号均可登录；管理员、运营可进入卡次管理并开户/调整；带领人、财务只能查询卡次。匿名请求卡次接口返回 401，带领人尝试开户或确认结算应返回 403。
2. **期次与报价**：新增期次默认自动预览封面；改期数后数字随之更新，切换手动上传后图片保留。报名与付款筛选可选择最近5期，输入 `0002` 应匹配期次10002，选择10002则精确匹配；重置恢复全部。轻友端能看到期次 10001 和 3 个活动日；报价展示为参考金额，不得显示成已结算金额。
3. **报名联系人与参与者**：用真实微信测试号发起两人报名，发起人是主要联系人，两名实际参与者各有独立报名/参与记录；同行手机号留空，不得自动填入发起人手机号。
4. **报名与结算状态**：报名待确认、已确认、已取消与结算待确认、已确认分别展示；轻友端只能看到工作人员确认结果，不能执行现金支付或扣卡。
5. **现金结算**：后台或移动工作台确认现金结算后，最终金额及方式在轻友端显示；期次公开报价仍保持原值，重复确认不得生成重复结算。
6. **多人卡次结算**：给报名发起人开卡，再尝试选择同行人的账户，应拒绝且余额不变；选择发起人的账户成功后，只扣该账户，流水和结算状态同时更新。
7. **单人后台报名扣卡**：单人后台报名选择实际参与者本人的卡次账户；选择其他轻友账户应拒绝。
8. **余额和重试**：余额不足、已确认重入、重复请求都不得再次扣卡或留下部分结算记录；卡次余额不得为负。
9. **卡次展示**：轻友端只显示当前剩余可用卡次和消耗记录；后台可以查询、开卡和按流水调整，不直接覆盖余额。
10. **体验记录隐私**：活动前后私人感受默认只对本人可见；未明确同意分享的内容不得进入轻读或公开分享。
11. **移动工作台授权**：授权前「工作人员工作台」入口不可见；绑定后按 `canOperate`、`canPayment` 分别验证操作；停用授权后入口和 API 访问立即失效。
12. **结算撤销与重新确认**：已确认结算只能由管理员按当前结算轮次撤销；撤销后回到待确认并可修改原报名后重新确认。卡次撤销保留原消费流水并追加 `void` 流水，不允许部分撤销或退到同行人账户。
13. **轻友首次登记**：小程序四步表单必须完成必填校验和敏感信息主动授权；成功后复用或更新 `ql_customer` 主档并新增一条 `ql_friend_assessment`。
14. **轻友重复登记**：同一微信轻友再次提交时仍只有一个主档，新登记必须追加，历史记录不得覆盖；同一请求号的相同内容幂等返回，不同内容复用请求号必须拒绝。
15. **健康选项与员工共享**：选择“无”应取消其他身体情况，选择其他情况应取消“无”；内部员工统一共享完整手机号、健康、用药和孕期信息。V1.4.5 进一步补齐四员工角色服务记录/附件读取和父级导航。执行 V1.4.4 后，`ql_admin`、`ql_operator`、`ql_leader`、`ql_finance` 均获得 `life:assessment:sensitive`，已有登录会话应重新登录以刷新权限；未获授权的账号继续脱敏或拒绝访问。导出权限仍单独校验，本次不增加导出或结算权限。
16. **档案、统计与导出**：后台能按姓名、小名、手机号和登记条件检索，查看倒序历次登记；统计按提交时间计算且多选独立计数；导出当前筛选范围的“轻友”和“登记记录”两个 Sheet。

17. **省市与登记历史**：城市为省 / 市两级原生选择，已有纯文本城市需重新选择；登记页底部「过往登记」可打开本人倒序历史与完整详情。检查新登记与历史修改分别使用新增和更正接口，修改不增加登记次数；草稿按已认证轻友编号保存，不能出现其他账号或旧无归属草稿。
18. **48 小时更正边界**：提交后 48 小时内，打开记录并完成四步校验、重新主动授权后可修改；到达首次提交后的截止时间即只读，后续修改不能延长期限。更正同一请求号重试返回同一结果，过期、其他账号、匿名与过时版本均被拒绝。更正较早登记不得覆盖最新主档；早期未保存基本信息快照的记录必须显示来源提示。
