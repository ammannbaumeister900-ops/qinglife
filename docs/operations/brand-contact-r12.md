## 页面变化

- 我的：桃子微信号 **qinglife2014**；点击“复制微信号”后到微信搜索添加，微信号也支持长按选中。复制失败时保留号码并提示手动复制。未登录、演示模式或联系人接口暂时不可用时，仍可看到已经批准公开的联系方式。
- 联系接口：已有运营配置的非空值继续优先使用；未配置、空白或旧空值回退到桃子 / qinglife2014。使用既有 sys_config 和 /app/qinglife/contact，不增加数据表或迁移。
- 首页：保留居中固定标题栏；在诗句上方与引导语并排放置小幅透明 Logo。原图的白字在浅底上难以辨认，新增暖鼠尾草色适配版本，原始 logo.png 未覆盖。诗句仍保留留白与错行布局，不增加句号。
- 邀请：保留“留白、同行、花开”三种邀请笺，主体改为新鲜蔬菜与水果，继续使用原有推荐路径与期次选择。我的邀请入口也将花瓶装饰改为蔬果。
- 四大基石：图片使用“心态平和 · 睡好觉 / 鲜活饮食 · 多运动”；“鲜活饮食”对应多吃新鲜、有生命力的食物。采用清晨光线、水彩蔬果和浅暖底色，避免堆叠床、器械或人物导致画面杂乱。

## 便捷添加微信好友的调研

核查日期：2026-10-04。开发者网站部分页面无法直接读取，以下依据微信官方维护的 [API 类型与说明](https://github.com/wechat-miniprogram/api-typings/blob/master/types/wx/lib.wx.api.d.ts)。

| 方式 | 公开能力与限制 | 本轮处理 |
| --- | --- | --- |
| 复制微信号 | wx.setClipboardData 可将号码写入剪贴板；添加个人好友仍需用户在微信中搜索并发起 | 已实现，附手动复制兜底 |
| 直接添加个人微信好友 | 在已核查的公开 API 中未找到该接口；这是对公开能力的调研结论，不代表非公开能力声明 | 不展示会误导用户的“一键加好友”按钮 |
| 添加手机通讯录联系人 | wx.addPhoneContact 写入手机系统通讯录；不是微信好友关系 | 不作为个人微信加好友方案 |
| 一键打开微信客服 | wx.openCustomerServiceChat 在点击后调用，需要企业 corpId 和客服 extInfo.url；打开的是客服会话 | 可作为后续客服方案，当前未配置和接入 |

建议当前继续使用明确可用的“复制微信号 → 微信搜索添加”。如未来需要少一步进入咨询，可另行配置微信客服，但需明确其与桃子的个人好友关系不同。
