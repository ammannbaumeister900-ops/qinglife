# 心声语音入口与提交交互修复

2026-10-04 微信验收反馈：语音入口不明显，点击录音后正文及匿名选项持续置灰，且“提交心声”和“仅自己保存”使流程重复。

正文下增加独立的浅绿“语音输入”区域，显示“点击录音”、最长45秒说明、结束录音和取消操作。文字与匿名选项在录音准备、录音、转文字以及隐私授权时都可编辑；只在提交请求进行时短暂锁定，避免重复提交和混入其他内容。语音结果保留为可修改的候选文字，点击“加入草稿”才合并到最新正文，不自动保存或发布。

取消与失败路径均可恢复：弹框失败、授权拒绝、准备超时、未触发录音开始、离开页面都会取消当前操作。迟到的授权或识别结果不得重新启动录音或覆盖后续内容；本地临时音频清理。麦克风拒绝时显示设置入口。

使用微信的 getPrivacySetting 判断是否需要隐私授权，并以原生 agreePrivacyAuthorization 按钮同步同意；提供打开平台隐私保护指引与“先写文字”选项。腾讯云语音处理用途仍逐次确认，不绕过麦克风或隐私授权。机制参考[微信官方 API 示例](https://github.com/wechat-miniprogram/api-typings/blob/master/types/wx/lib.wx.api.d.ts)。平台后台的麦克风隐私声明及真机系统授权需要设备验收。

只保留一个“提交心声”按钮，始终发送 submit 和公开同意，进入审核后才可前台展示；默认小名署名，可随时改为匿名，匿名显示“本期轻友”。修改后重新提交再次审核。提交未结束的语音时，以此刻正文和匿名选择为准并取消语音；尚未确认加入正文的候选文字不自动提交。历史私人草稿和撤回功能仍可读取使用，无数据库变更。

验证：28项相关小程序测试通过，覆盖授权取消、超时、录音错误、离开页面、本地音频删除、识别与编辑并行、提交竞态及旧记录兼容。微信开发者工具的8组真实编译界面检查通过，检查各语音状态下输入框、匿名和提交属性，实际点击匿名、取消及加入草稿。系统授权与腾讯云调用在本轮界面检查中使用隔离测试条件，本轮没有真实麦克风录音，也没有新增腾讯云调用。后端沿用此前已部署的 R14，不重启、不迁移数据库。生产未修改。
