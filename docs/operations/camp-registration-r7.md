# 轻体营报名与服务页 R7

本轮在 R6 小名／匿名心声规则上调整报名及个人展示。改动保存在现有工作分支，未提交或推送。

## 页面行为

1. 轻体营频道保留固定导航标题；正文以细线、留白短句和“近期相聚”引导进入活动卡。
2. 本人报名和主要联系人的默认称呼读取真实档案字段 ql_customer.nickname；真实姓名保留在 profile.name，不再冒充小名。小名缺失时，报名可填写称呼，“我的”显示可点击的“点击登记你的小名”，进入现有轻友档案登记页。
3. 报名第一步“继续”，第二步“上一步／提交报名”固定在底部，背景不透明，兼容底部安全区。内容预留至少 200rpx 加安全区；切换步骤回到顶部。
4. 新报名的服务必要信息默认勾选，用户取消后阻止提交；返回上一步、再次进入确认、刷新仍保留取消选择。仅用于既有报名服务处理，不影响心声的独立投稿与审核规则。
5. 确认页为一张卡，包含人数与小名、联系人、简短参考价和必要信息勾选。日期与活动名称只在页头呈现。
6. 已有报名从报名入口或活动详情进入“轻体营服务”，即使期次已满或已停止报名也可查看。服务页集中展示报名状态、付款／卡次状态和心声入口，无签到按钮。
7. 心声仍限定本人实际参与记录。开营当天可填开营心声，结束后可补写；默认小名投稿，可选择匿名，审核后才展示。ASR 保持关闭。

付款显示沿用已有服务端结果：结算未确认显示“金额待确认”；确认现金金额后显示待付款／已付款／无需付款；确认卡次显示“已用卡次”。前台不推算参考价为应付金额。
