## 已纳入功能

- 小程序四频道：首页品牌 Logo、诗句留白和柔和底色；居中固定标题、不透明底栏；更多故事直达轻友故事、搜索清除交互和文章固定返回。
- 轻体营与我的：小名优先、无小名引导登记；报名步骤、底部固定操作与精简汇总；已报名进入服务详情；集中展示报名和付款状态、卡次账目与邀请入口。
- 老带新与登记分享：所有登录轻友可选三张蔬果邀请图，按期次生成小程序分享卡片；推荐归属和报名记录；运营分享本期登记表，轻友登录后填写并计入本人历史，暂不发奖励。
- 轻友心声：统一输入框，开营当天起持续可写；长按语音、松开转文字，可编辑与重置；单一提交进入审核，默认小名、可选匿名。后台保留原文，展示内容可编辑；下架后可修改，保存仍下架，单独重新展示。对应期次滚动展示并支持全文查看。
- 后台：卡次备注和选填单图、有效期调整、最新可用账户及默认次数；报名确认后统一确认付款、随状态显示操作；统计按期次快捷筛选；内部账号按称呼和掩码手机号展示、账号页面权限配置。
- 联系方式：桃子微信号 qinglife2014，可复制。

数据库增量迁移包含 V1_4_4 至 V1_4_13，隔离验收已到 1.4.13。后续部署须通过现有迁移流程，不能只替换代码而跳过迁移。
