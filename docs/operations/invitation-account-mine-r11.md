# R11 内部账号、我的布局与邀请轻友

更新日期：2026-10-04。部署于既有隔离验收环境；生产未更新，代码未提交或推送。

## 本轮行为

- 内部账号管理：用轻友档案小名作为称呼，尚未登记时沿用微信称呼；列表与授权候选项展示“称呼 · 138****1234”，没有有效手机号时显示“未登记手机号”。支持按称呼或手机号片段搜索，不再按账号编号搜索。服务端只返回掩码，仍按选择的账号 ID 绑定授权，同名账号不会自动匹配或合并。后台工作人员原有权限保持原值。
- 首页已确认或已完成的报名提醒收起；报名及付款状态集中在轻体营服务页。待确认、候补或安排变化的首页提醒继续显示。
- 我的页面：个人信息下方设置完整宽度的邀请入口；卡次改为单独的账目区，展示当前可用余额和最近三次消耗；保留全部参与经历入口，移除当前期次的重复进度卡片。各区块按正常文档流排列，保留间距。
- 邀请轻友：所有已登录轻友都能制作邀请，不要求完成本人体验。三张固定邀请图为留白、同行、花开，可自由切换。选择开放报名的期次后生成专属邀请，通过微信小程序卡片发给朋友或微信群；卡片标题包含期次，路径包含后端生成的邀请代码，图片保持固定设计。
- 分享资格的放开只影响邀请；老轻友优惠资格、本人感悟权限、首次推荐归属及每期推荐记录沿用原业务规则。推荐记录仅展示小名、期次、报名状态和时间，暂不发奖励。

## 验收入口与步骤

[管理后台](https://qinglife.guijianju.cn/accept-20261001-admin/)

[R11 微信扫码预览](../../.tools/acceptance-20261004-invitation-r11/wechat-invitation-r11.png)

1. 后台进入权限管理 → 内部账号管理 → 新增授权，搜索轻友小名或手机号，确认称呼与掩码手机号。编辑原授权时确认原绑定保持。
2. 小程序登录后进入我的，确认邀请入口位于个人信息下方；卡次账目与下方目录之间没有交叉，也不重复展示当前报名进度。
3. 点邀请轻友，切换三张邀请笺，选择一个开放报名的期次，生成邀请后分享到微信群。
4. 由另一个微信账号点开卡片，确认期次正确；登录并报名后，推荐人可在相聚的回音查看小名及报名状态。
